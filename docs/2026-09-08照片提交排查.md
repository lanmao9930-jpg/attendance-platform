# 2026-09-08 签到照片故障排查

## 已确认的现象

用户视频中，表单、节次和照片已经选择，点击提交后出现空白红色提示。线上健康接口和学期日历正常，允许当天签到；按视频中的照片文件名查询，未找到对应的原始提交记录。

旧版 fileToImage 直接将 Image.onerror 的事件作为 Promise 拒绝值。提交失败处理只读取 error.message，浏览器事件没有该字段，会显示空白错误。隔离测试已复现同样的事件和空白提示路径。仅凭视频无法进一步确认原照片是损坏、解码不兼容还是其他手机环境问题。

## 修复内容

- 使用 FileReader 数据地址读取照片，不再依赖照片的临时 blob 地址。
- 对照片读取和图片解码分别设置超时，错误一律转换为非空文字。
- 压缩失败时，可识别且不超过 2 MB 的 JPG、PNG、WebP 原图可以直接提交。
- 无法处理的格式、大图、读取失败明确提示重新选择或重拍，保留表单内容。
- 错误位于提交按钮附近并自动进入可见区域，提交过程区分处理照片和上传。
- 网络异常、无效接口响应、请求超时都有可理解的提示。
- 保留原来的扫码有效期、真实提交时间和管理员权限校验，没有为视频中的同学补写考勤。

## 验证

- 照片解码失败、解码超时、Canvas 不可用、读取失败、读取超时、异常格式和体积限制测试。
- 无 message 的事件、缺失错误原因和非 JSON 接口响应测试。
- 隔离 API 集成测试通过。
- 手机尺寸浏览器中模拟图片解码失败，小 JPG 原图成功提交到本地测试服务。
- 无效图片展示中文错误并保留已填内容；更换图片可继续提交。
- 正常照片经过真实浏览器压缩后，签退提交成功。

测试照片和模拟服务仅用于本地隔离验证，不写入线上学生原始记录。
